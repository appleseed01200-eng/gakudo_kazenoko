# 風の子学童クラブ 営業提案用デモ v2.0

2026年10月21日／水色・青を主体とする改訂版

## 開く

ZIPは「すべて展開」し、中の index.html を通常のブラウザーで開いてください。
HTML・CSS・JavaScriptによる13ページのサイトです。インストール・ビルド・ネット接続は不要です。
掲載元・外部地図へのリンクのみ、ネット接続が必要です。
検証環境のブラウザーはfile://を許可しないため、同じファイルをPC内のローカルHTTPで検証しています。

## 今回の変更

- 風の子学童の既存サイトに掲載されている実写真9点を取得して使用しました。この版にAI生成写真は含まれません。
- 写真の青い「風の子」Tシャツに合わせ、水色の背景と鮮やかな青を中心に再デザインしました。
- トップの構図、写真の配置、案内カード、日記、各ページの冒頭、問い合わせへの案内を作り直しました。
- 日記3件は、既存サイトのクリスマス会・運動会・キャンプの記事と写真を要約・再構成しています。新しい開催報告ではありません。

## ページ構成

index.html：トップ／about.html：施設紹介・保育方針／day.html：1日の流れ／events.html：年間行事・写真アルバム／team.html：指導員・運営／admission.html：入所・料金／diary.html：日記一覧／diary-craft.html：クリスマス会／diary-play.html：運動会／diary-camp.html：キャンプ／faq.html：FAQ／contact.html：見学・非送信フォーム・アクセス／sources.html：参照元・確認待ち事項。

スマホでは上部のメニューを開いて移動できます。日記はカテゴリーで絞り込みできます。FAQの質問を押すと回答を開閉できます。
フォームには架空の内容を入力してください。確認画面と完了画面を試せますが、送信・予約・メール作成・保存は行いません。

## 写真・情報・公開

写真はユーザーの明示的な指示に基づき、既存サイトから非公開の営業提案デモへ使用しています。
素材の元URL・掲載ページ・ハッシュは ASSETS.md と 素材台帳.json に記録しています。
元の解像度・画像内の文字や加工を保ち、表示上の切り取りのみCSSで行っています。
風車の仮マークと文字組み、アクセス概略図はデモ用デザインです。
正式な外部公開等の利用範囲の確認は、今回の非公開デモとは分けて扱います。

施設情報は旧サイト・移転先の掲載を要約し、現行条件は確認待ちとして区別しています。
八尾市の参考ページから金額や利用条件を転用していません。未確認の金額・職員プロフィール・保護者の声は創作していません。
全ページに非公式デモを表示し、インターネットには公開していません。

## 同梱資料と版管理

SOURCES.md：参照元／確認待ちリスト.md：本制作前の確認事項／ASSETS.md・素材台帳.json：使用写真／CHANGELOG.md：変更履歴／動作確認結果.md・検証記録/：点検結果／確認画面/：PC・スマホの画面。
前版v1.0は別フォルダーと既存の納品ZIPに保管し、今回のv2.0と分けています。v2.0のZIP内に旧版のAI写真は含めていません。
デスクトップを更新する際も、旧フォルダーを版バックアップに移して保存します。
編集時は各HTML、assets/base.css・style.css、assets/site.js を修正してください。編集前に必ずフォルダー全体を版名付きで複製してください。
